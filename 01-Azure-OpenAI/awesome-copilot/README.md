# 🌟 Awesome Azure OpenAI & Copilot Guide

Welcome to the **Awesome Azure OpenAI & Copilot** references section!

Due to copyright and licensing considerations, we do not host a direct, hardcoded copy of the expansive community lists here. Instead, this folder serves as a **launchpad** directing you to the absolute best, officially maintained repositories and curated lists for building on the Microsoft AI stack.

## 🚀 The Official Master List

The definitive, continuously updated collection of Microsoft Azure OpenAI & Copilot ecosystem resources (including services, frameworks, agent platforms, and evaluation tooling) is maintained directly by Microsoft.

➡️ **[Visit the Official `microsoft/awesome-copilot` Repository](https://github.com/microsoft/awesome-copilot)**

## 📚 Key Learning Areas to Explore

When reviewing the official lists, we highly recommend focusing on these core areas:

1.  **Agent Frameworks**: Deep dive into tools like [Semantic Kernel](https://github.com/microsoft/semantic-kernel) and [AutoGen](https://github.com/microsoft/autogen) for multi-agent workflows.
2.  **LLMOps & Evaluation**: Explore how to use Azure Prompt Flow and the [AI Evaluation SDK](https://learn.microsoft.com/en-us/azure/ai-studio/how-to/develop/evaluate-sdk) to measure the groundedness and coherence of your models.
3.  **Copilot Development**: Discover hands-on guides for extending Microsoft 365 Copilot, deploying custom Copilot Studio bots, and utilizing the new Microsoft 365 Agents SDK.
4.  **Advanced RAG (Retrieval-Augmented Generation)**: Look for Azure-specific solution accelerators that combine Azure AI Search (Hybrid/Vector) with Cosmos DB and Azure OpenAI endpoints.
